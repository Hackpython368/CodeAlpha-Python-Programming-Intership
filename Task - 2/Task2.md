# Task 2: Stock Portfolio Tracker 📈

## Objective

Build a simple stock portfolio tracker using Python that calculates the total investment value based on user-provided stock quantities and predefined stock prices.

## Task Description

In this task, the user enters stock names along with the quantity owned. The program uses a predefined dictionary containing stock prices to calculate the total value of the portfolio.

The application should display the total investment amount and may optionally save the portfolio details to a `.txt` or `.csv` file for future reference.

## Requirements

* Use a hardcoded dictionary to store stock prices.
* Accept stock names and quantities from the user.
* Calculate the value of each stock holding.
* Display the total portfolio value.
* Optionally save the results in a `.txt` or `.csv` file.

## Concepts Used

* Dictionaries
* User Input and Output
* Variables
* Basic Arithmetic Operations
* Conditional Statements
* Loops
* File Handling (Optional)

## Learning Outcome

By completing this task, you will learn how to work with dictionaries, process user input, perform calculations, and optionally store data in files. This project also provides practical experience in handling real-world data and building simple financial tracking applications.
