# Task 3: Task Automation with Python Scripts ⚙️

## Objective

Develop a Python script to automate a simple real-life repetitive task. The goal is to reduce manual effort and improve efficiency by using Python automation techniques.

## Task Description

In this task, a Python script is created to perform an automated operation without requiring repetitive manual work. The project can focus on file management, text processing, or basic web data extraction.

Possible automation tasks include:

* Moving all `.jpg` files from one folder to another.
* Extracting email addresses from a text file and saving them to a separate file.
* Scraping the title of a webpage and storing the result.

## Requirements

* Select one automation task.
* Process data automatically using Python.
* Handle files or web content as required.
* Display or save the generated output.
* Ensure the script is simple, reusable, and efficient.

## Concepts Used

* File Handling
* Python Modules
* OS Operations (`os`)
* File Management (`shutil`)
* Regular Expressions (`re`)
* Web Requests (`requests`)
* String Manipulation

## Learning Outcome

By completing this task, you will understand how Python can be used to automate repetitive activities. You will gain practical experience in working with files, directories, text processing, and external resources, making everyday tasks faster and more efficient.
