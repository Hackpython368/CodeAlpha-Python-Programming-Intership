# Task 1: Hangman Game 🎮

## Objective

Create a simple text-based Hangman game using Python. The player has to guess a hidden word one letter at a time. The game continues until the player either guesses the complete word or uses all available attempts.

## Task Description

In this task, a random word is selected from a predefined list of words. The player enters one letter at a time to guess the word. If the guessed letter is present in the word, it is revealed in its correct position. Otherwise, the number of remaining attempts decreases.

The player is allowed a maximum of **6 incorrect guesses**.

## Requirements

* Use a predefined list of 5 words.
* Select a word randomly.
* Accept user input from the console.
* Display the current progress of the word.
* Limit incorrect guesses to 6.
* Display appropriate win or lose messages.

## Concepts Used

* Python Variables
* Lists
* Strings
* Loops (`while`)
* Conditional Statements (`if-else`)
* User Input
* Random Module

## Learning Outcome

By completing this task, you will gain hands-on experience with Python fundamentals, including loops, conditions, string manipulation, list operations, and user interaction through the console.
